# 项目事实与判据

本文汇总由底稿与考察资料提炼的项目级事实。工艺细节以 `data/**` 中的注释为准。

## 一、项目公理

- **A1 热力学**：反应势垒只能通过能量输入与温度提升克服。火星缺乏还原性气氛、化石燃料与石灰石；碳、氢、氯、氟均须先制备。
- **A2 精度继承**：制造母机的精度不低于被制造机器的精度。精度不能自举，只能继承。
- **A3 闭合度**：项目进度以“进口依赖项”的数量衡量，不以产能或吨位衡量。

## 二、火星环境

- 大气压 610 Pa；CO₂ 95.3%、N₂ 2.7%、Ar 1.6%、O₂ 0.13%。
- 重力 3.71 m/s²；平均温度 −63 °C（−125 ~ +20 °C）。
- 太阳常数 586 W/m²；尘暴可遮蔽 90% 光照，光伏系统须具备 3–5 倍冗余。
- 表面尘含高氯酸盐 0.5–1%，具有毒性、磨蚀性，并会污染光学与密封系统。
- 表面辐射约 0.6–0.7 mSv/天。

## 三、物质基底

- 风化层厚 3–10 m；SiO₂ 44–46%、FeO+Fe₂O₃ 17–20%、Al₂O₃ 8–10%、MgO 6–8%、CaO 5–7%、SO₃ 5–8%、Na₂O+K₂O 2–4%、TiO₂ 0.8–1.3%、Cl 0.5–1%。
- 铁相可磁选；硫酸盐富裕；磷仅来自磷灰石；铜、镍、铬含量低。
- 水：极冠冰约 1.6×10⁶ km³；中纬度浅埋冰与含水矿物可用；选址第一原则为水。
- 不存在石油、煤、天然气与萤石；稀土约百 ppm，钨不足 1 ppm。

## 四、关键闭合环节

1. 催化剂环：氨、硫酸、费托、甲醇、加氢。
2. 精密件环：轴承、密封、弹簧、丝杠、光栅尺。
3. 试剂环：电子级 HF、H₂O₂、光刻胶、蚀刻气。
4. 有机环：聚合物、橡胶、润滑脂、树脂；由 CO₂ 与 H₂ 重建。

## 五、种子与自举

- 种子 8 条（以 `data/floor/seed.ts` 为准）：机器人、车床、磨床、熔化炉、量块、控制板、高压试验台、聚变装置（ITER 级 D-T 托卡马克 + 发电模块；连续运行与发电为假设，氚增殖不要求）。
- 核原料（氘、氚等聚变燃料）按**无限供应**处理；本地 D/T 路线只作为能力备份，不构成来源约束，氚增殖不再是要求。
- 种子工厂原则：可由车床制造者不运输；决定精度的设备必须运输两套。
- 设备链构成闭环；其入口为一台不使用金属件、仅以人工与土料建造的窑。
- 电子环节可由四类方案降级替代：电阻炉、接触器、旋转变流机、机械计数器。

## 六、关键瓶颈

- 催化剂体系不能自我复制；须依靠一次性输入与冗余库存打断循环。
- 6 mbar 下对流散热失效，余热依靠辐射板排放；10 MWe 余热需数万平方米散热面积。
- 高氯酸盐污染全厂，催化剂车间须独立洁净。
- 碳在系统中作为载体，不作为净消耗品；CO 与 CO₂ 须闭环。
- 外压 6 mbar，正压容器压差约 10 t/m²；法兰与密封按外压容器设计。
- 低重力下自然对流消失，精馏、沸腾与冷凝退化为扩散控制。
- 磷、铜为稀缺资源；镍、铬是不锈钢与耐热合金的长期瓶颈。

## 七、工艺水平

- 200–400 nm 栅长、5 µm 设计规则、100 mm 晶圆。
- 40 nm 需 EUV；`plant/euv-stepper` 的 overlay 560 nm 档可测（`measure/euv-overlay`），field 2 mm、9.7 片/h；43 nm 为专用片级预算，不是整机指标，亦不代表 40 nm 已通。
- 光刻能力达到 5–10 µm 级；封装仍缺金丝与塑封料。

## 八、能量成本

单位为 MJ/t，数量级如下：

- 钢铁 2×10⁴；铝 1.5–2×10⁵；MG-Si 5×10⁴；SOG-Si 5×10⁵；单晶硅片 2×10⁶。
- 玻璃 1×10⁴；氨 3×10⁴；硫酸 2×10³；液氧 2×10⁴；液氢 1.5×10⁵。

## 九、核心反应

- **水与气**：冰升华/冷凝；2H₂O 电解 → 2H₂ + O₂（1.8–2.2 V）；CO₂ + 4H₂ → CH₄ + 2H₂O（573–673 K）；CO₂ + H₂ → CO + H₂O（673–1073 K）；N₂ + 3H₂ → 2NH₃（673–773 K、15–30 MPa）；NH₃ 氧化 → HNO₃（1073 K、Pt-Rh）。
- **铁**：Fe₂O₃ + 3H₂ → 2Fe + 3H₂O（773–1073 K，首选）；CO 还原；碳热还原（1473–1673 K）；磁选先富集。
- **硅**：SiO₂ + 2C → Si + 2CO↑（1873–2073 K）；Si + 3HCl → SiHCl₃ + H₂；SiHCl₃ + H₂ → Si + 3HCl（西门子法）；区熔至 99.9999%。
- **铝**：拜耳法 → Al₂O₃；Hall–Héroult 2Al₂O₃ + 3C → 4Al + 3CO₂↑（1233–1253 K，冰晶石须自造）。
- **其他金属**：Mg 皮江法/碳热（1473 K、真空 10 Pa）；Ca 硅热法；CaC₂（2273 K）；Ti 氯化 + Mg 还原；Cr 铬铁；Ni 羰基法；Cu 硫化物/湿法；Zn 碳热法；Na/K 电解或碳热法；W/Mo 氢还原；稀土酸浸/萃取/熔盐电解。
- **酸碱盐**：H₂SO₄ 接触法；HCl 盐析/合成；HF 萤石 + 硫酸（523 K，铅/PTFE）；H₃PO₄ 湿法；氯碱；索尔维纯碱（需氨）。
- **有机物**：CO₂ + H₂ → CH₃OH；费托；MTO 制乙烯/丙烯；CaC₂ + H₂O → C₂H₂；乙炔环化 → 苯；甲醇羰基化 → 醋酸；甲醛、环氧乙烷、乙二醇、尿素；硅橡胶、PTFE、润滑脂、硝化棉。
- **无机非金属**：钠钙玻璃、硼硅玻璃、石英玻璃、刚玉、SiC、Si₃N₄、耐火材料、镁水泥/硫铝酸盐、石膏、分子筛、活性炭。
- **半导体**：多晶硅 → 单晶（直拉/区熔）→ 氧化 → 掺杂（POCl₃/BBr₃/离子注入）→ 光刻胶 → 蚀刻 → 金属化 → 封装；超纯水 18.2 MΩ·cm。

## 十、设备分类

- **A 采矿与物料**：采掘、破碎磨矿、磁选/浮选、空分、水开采、机械输送。
- **B 高温与冶金**：回转窑/竖炉/电弧炉/感应炉/电阻炉/太阳炉；精炼；焙烧；熔盐电解；铸锻；粉末冶金；热处理。
- **C 冷加工与母机**：车床/铣床/磨床/加工中心/电火花；压力机/折弯/卷板/拉丝；焊接；表面处理；量具与检测。
- **D 化工装置**：反应器、精馏/萃取/结晶/膜分离、换热与辐射散热、泵阀真空、过滤分离、储罐、仪表。
- **E 电气与电子**：核电/光伏、电力电子、电机与减速机、线缆、真空管/分立器件/IC、传感、PLC。
- **F 公用工程**：微电网储能、惰性气站、辐射散热、制冷、气体回收、水系统、废物处理、洁净室。
- **G 勘测与地质**：遥感、探地雷达、钻机、原位分析、测绘与导航信标。
- **H 生活与生物辅助**：密闭生态、生物炼制、微生物冶金、水培。

## 十一、种子工厂与实施阶段

- 种子工厂约 **750–1000 t**（不含首台聚变装置）：母机 120 t、量具 8 t、冶金 80 t、化工 90 t、机器人 300 t、试剂种子 50 t、备件 60 t、设计数据 0.1 t。首台 ITER 级聚变装置约 **23 000 t**，发电岛另计；旧表“能源 40 t”作废。
- 目标不是产能，而是 **5 年内复制出第二套自身**；第一优先级为母机环、量具环与轴承/密封。
- 四条制造链：结构件（磁选→氢还原→电弧炉→连铸→轧制）；电气电子（铜/硅→器件→封装）；化工（CO₂/H₂O/N₂/风化层→氨/硫酸/氯碱/有机物）；精密件（轴承钢→磨削→量块/干涉仪继承）。
- 实施阶段：P0 选址 → P1 生存电力 → P2 冶金 → P3 母机复制 → P4 化工全环 → P5 精密电气 → P6 电子半导体 → P7 工业文明（100–250 火星年）。
- 闭合度按本地可制造 BOM 的质量占比与价值占比加权计算；仅看质量会高估。
- 易忽略的工程细节（15 项）：冰再冻堵、硫酸铅衬里、石墨电极、冰晶石自造、CaC₂ 2273 K、玻璃窑耐火砖、精馏填料、电解隔膜、焊料 Sn、硬质合金刀具、切削液、滤材、焊接保护气、导航/时间基准、批次一致性。

## 十二、空间与时间拆分

聚变装置与后续工厂按空间（在哪里）与时间（什么时候）两个轴拆分。模型没有位置与排程字段：位置只落在注释与本节的表里，时间只落在 `Route.rate`、`Step` 顺序与 `Component.wear`，不构成排程或工期。

### 空间

| 空间 | 内容 | 数据现状 |
|---|---|---|
| 地球 | 首台聚变装置、8 条种子、一次性输入 | 种子 8 条；运输、着陆与卸载未建模 |
| 火星轨道/着陆 | 进入、下降、着陆、卸载 | 无条目、无路线 |
